# Nội dung tài liệu sản phẩm cần bên A bổ sung

Lập 07-10-2026 từ lượt "AI tự đặt câu hỏi": đây là các nhóm câu khách hay hỏi mà
tài liệu sản phẩm hiện tại KHÔNG trả lời được. Ở chế độ chỉ chọn trong kho, AI sẽ
đáp "em ghi nhận, bên em liên hệ hỗ trợ sau" cho mọi câu thuộc các nhóm này.

Đây là chính sách riêng của ngân hàng nên KHÔNG ai ngoài bên A được tự điền. Điền
xong thì chép câu trả lời vào đúng tài liệu sản phẩm (trang Tri thức AI -> Tài
liệu nguồn), rồi bấm "AI tự đặt câu hỏi" để kho tự soạn đáp án.

Danh sách câu hỏi nguyên văn nằm ở trang Tri thức AI, bảng "Câu khách hỏi mà kho
chưa có" (nhãn "AI tự đặt câu hỏi").

## Dùng chung cho các sản phẩm vay (vay_tin_chap, vay_mua_nha)

| Khách hỏi | Bên A điền |
|---|---|
| Người làm nghề tự do, không có hợp đồng lao động có vay được không? Cần giấy tờ gì thay thế? | |
| Nhận lương bằng tiền mặt, không có sao kê thì chứng minh thu nhập bằng gì? | |
| Hộ kinh doanh cá thể có vay được không? | |
| Chưa có sổ bảo hiểm xã hội có vay được không? | |
| Đang có khoản vay ở ngân hàng khác thì có được xét tiếp không? | |
| Ở tỉnh khác có đăng ký được không? Áp dụng ở những tỉnh nào? | |
| Có đăng ký trực tuyến / qua ứng dụng được không, hay phải ra chi nhánh? | |
| Từ lúc nộp đủ hồ sơ đến lúc có kết quả duyệt mất bao lâu? | |
| Kết quả duyệt được báo qua kênh nào (tin nhắn, điện thoại, chi nhánh)? | |
| Ngoài lãi suất còn những phí nào (phí hồ sơ, phí bảo hiểm khoản vay, phí khác)? Bảo hiểm có bắt buộc không? | |
| Chậm trả thì bị tính phạt thế nào (mức phạt, tính từ ngày nào)? | |
| Trả trước hạn một phần / toàn bộ: phí bao nhiêu, thủ tục thế nào, cần mang gì? | |
| Có được đổi kỳ hạn trả nợ giữa chừng không? | |
| Lãi tính trên dư nợ giảm dần hay dư nợ gốc? Cố định hay thả nổi? | |
| Có được vay ít hơn hạn mức tối đa không? Mức vay tối thiểu? | |
| Thu nhập phụ (thưởng, hoa hồng, nguồn khác) có được tính không? | |
| Ưu đãi cho khách vay lần đầu / khách trẻ? | |
| Ngân hàng nhắc nợ bằng cách nào? | |

## Riêng vay mua nhà

| Khách hỏi | Bên A điền |
|---|---|
| Có cần vốn tự có / đặt cọc trước không? Tỉ lệ bao nhiêu? | |
| Tài sản bảo đảm được chấp nhận là gì? | |

## Thẻ tín dụng

| Khách hỏi | Bên A điền |
|---|---|
| Thu nhập tối thiểu để mở thẻ? Những đối tượng nào được mở? | |
| Người làm tự do / nhận lương tiền mặt có mở được không? | |
| Từng chậm trả hoặc có nợ xấu cũ thì có được xét không? | |
| Mở thẻ trực tuyến được không? Thẻ gửi về đâu, ở tỉnh có nhận được không? | |
| Thời gian từ lúc nộp hồ sơ đến lúc nhận thẻ? | |
| Phí phát hành, phí thường niên từ năm thứ hai? | |
| Lãi suất trên dư nợ chưa trả hết, lãi/phí phạt chậm thanh toán? | |
| Rút tiền mặt tại ATM: được không, phí bao nhiêu? | |
| Hạn mức tối đa áp dụng cho ai? | |
| Ưu đãi, khuyến mãi hiện hành? | |

## Tiết kiệm

| Khách hỏi | Bên A điền |
|---|---|
| Rút trước hạn thì hưởng lãi bao nhiêu? Thủ tục tất toán trước hạn? | |
| Gửi online và gửi tại quầy lãi suất khác nhau thế nào? | |
| Có phí duy trì tài khoản tiết kiệm online không? | |
| Mở sổ / gửi online cần giấy tờ gì? | |
