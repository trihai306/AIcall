              Đây là thứ AI đọc để tư vấn. Mọi con số bot nói cho khách — lãi suất,
              hạn mức, điều kiện — đều lấy từ đây.

            chuyển thành bảng cho AI đọc, không phải gõ lại tay. File Word/PDF thì

              Ghi số cụ thể, đừng ghi khoảng mơ hồ. Bot đọc nguyên con số ở đây cho
              khách nghe — và có lưới chặn đối chiếu số trong câu trả lời với tài liệu này.
            

          

          

            
            
          

        

      

    


    

      

        

          

            
Nguồn dữ liệu

            

              File Excel/CSV/SQLite trên máy để bot tra cứu khi tư vấn. Chỉ nhận
              đường dẫn cục bộ — hệ thống chạy offline hoàn toàn.
            

          

          
        


        
        

          
Tải file lên máy chủ

          

            

              
            

            
          

          

            Nhận .db .sqlite (cơ sở dữ liệu) và
            .xlsx .csv (bảng tính), tối đa 200 MB.
            File lưu vào data/nguon/.
          

          

        


        

          

            
Tri thức chung
              Bảng giá, biểu phí, danh mục sản phẩm. Nạp vào kho tri thức, bot tìm gần đúng theo nghĩa.

            
Tra theo khách
              Dư nợ, đơn hàng. Khớp CHÍNH XÁC theo cột khoá (ví dụ số điện thoại), đọc thẳng từ file mỗi lần tra.
